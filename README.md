# 📱 Veyra Scroll

> Um aplicativo Android desenvolvido para proporcionar uma experiência de rolagem mais prática, fluida e personalizada.

---

## ✨ Sobre o projeto

**Veyra Scroll** é um projeto Android desenvolvido com foco em aprimorar a experiência de navegação e rolagem no dispositivo.

O projeto foi criado como parte dos estudos e experimentos de desenvolvimento Android, utilizando **Kotlin**, **Jetpack Compose** e as ferramentas modernas do ecossistema Android.

O objetivo é criar uma aplicação simples, leve e com uma interface moderna, servindo também como base para futuras funcionalidades.

---

## 🚀 Tecnologias

O projeto utiliza tecnologias atuais do desenvolvimento Android:

* 🟣 **Kotlin**
* 🎨 **Jetpack Compose**
* ⚙️ **Gradle Kotlin DSL**
* 🤖 **Android SDK**

## 🛠️ Como executar

### Pré-requisitos

Antes de começar, tenha instalado:

* [Android Studio](https://developer.android.com/studio)
* Android SDK
* JDK compatível com a versão do projeto
* Git

### Clone o repositório

```bash
git clone https://github.com/Swiftxzn/Veyra-Scroll-Apk.git
```

Entre na pasta:

```bash
cd Veyra-Scroll-Apk
```

### Execute no Android Studio

1. Abra o projeto no **Android Studio**
2. Aguarde a sincronização do Gradle
3. Conecte um dispositivo Android ou inicie um emulador
4. Clique em **Run ▶️**

### Ou compile pelo terminal

No Windows:

```bash
gradlew.bat assembleDebug
```

No Linux/macOS:

```bash
./gradlew assembleDebug
```

O APK de debug será gerado dentro da pasta:

```text
app/build/outputs/apk/debug/
```
